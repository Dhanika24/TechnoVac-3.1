Welcome to the **Technovac 3.1 PR Challenge**! Get your pull request merged in 20 minutes and win a prize. You will go through the full GitHub flow: **fork → pick an issue → open a pull request**. No installation needed. Everything happens in your browser.

## What you will do

Create your own **contributor card** (a small HTML page about you) and add it to this repository.

## Quick start

1. [**Fork this repo**](https://github.com/IEEE-Student-Branch-NSBM/TechnoVac-3.1/fork) and read [CONTRIBUTING.md](https://github.com/IEEE-Student-Branch-NSBM/TechnoVac-3.1/blob/main/CONTRIBUTING.md) (it has the 6 steps).
2. Pick the issue [**"Add your contributor card"**](https://github.com/IEEE-Student-Branch-NSBM/TechnoVac-3.1/issues/1) (issue #1) in the [Issues](https://github.com/IEEE-Student-Branch-NSBM/TechnoVac-3.1/issues) tab.
3. Create `contributors/YOUR-GITHUB-USERNAME.html` using [`contributors/TEMPLATE.html`](https://github.com/IEEE-Student-Branch-NSBM/TechnoVac-3.1/blob/main/contributors/TEMPLATE.html).
4. Open a pull request with `Closes #1` in the description.

## Finished early? Bonus task

Do your contributor card first. Then pick one fun-fact page issue (space, football, movies, food, or gaming) and create `facts/TOPIC-YOUR-GITHUB-USERNAME.html` using [`facts/TEMPLATE.html`](https://github.com/IEEE-Student-Branch-NSBM/TechnoVac-3.1/blob/main/facts/TEMPLATE.html). For example: `facts/space-octocat.html`.

Bonus pull requests are great practice, but they **do not count toward the prizes**.

| `technovac 3.1`          | A contribution made during the event                                         |

## 🏆 Winners

- The **first 5 correct pull requests** win.
- "Correct" means: you forked the repo, commented on the issue, created `contributors/YOUR-GITHUB-USERNAME.html` from the template, and wrote `Closes #1` in your PR.
- Your PR must be **merged** and have the `technovac 3.1 accepted` label.
- Order is decided by the time you opened your PR. PRs that break the rules are skipped.
- One win per person. No spam or empty files.
- Bonus pull requests (fun-fact pages) do not count.
